CPSI 11104 : Concepts of Programming

An introduction to computational thinking and software development using Python.

Course Overview

Concepts of Programming introduces students to the fundamentals of programming and computational problem solving. Students learn how to analyze problems, design algorithms, and implement structured programs using Python. The course emphasizes logical thinking, debugging, software design principles, and developing programming confidence through hands-on laboratory exercises.

Learning Objectives

By the end of the course, students will be able to:

  • Develop algorithmic solutions to computational problems.
  • Write well-structured Python programs.
  • Use variables, functions, loops, and conditionals effectively.
  • Work with common data structures including strings, lists, dictionaries, and tuples.
  • Read from and write to files and databases.
  • Design simple object-oriented programs using classes and inheritance.
  • Debug, test, and improve software solutions.

Course Format

Students learn through lectures, in-class programming demonstrations, hands-on laboratory exercises, quizzes, and programming projects. Emphasis is placed on writing correct, readable, and maintainable code while developing systematic problem-solving skills.

Programming Language

The course uses Python as the primary programming language. Python's simple syntax allows students to focus on computational thinking and software design before moving to more advanced programming concepts.
